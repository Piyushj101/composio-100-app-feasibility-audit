We asked an agent to case 100 APIs. It got 18% right on its own.

Every app below was researched by a real pipeline — a fetch agent that hit the actual docs URL, a knowledge pass that read the results, and a live-search verification loop that checked the riskiest claims. This page shows all three passes, including where the agent was wrong — not just the polished final table.

01
why the agent misses gates

Most SaaS docs pages contain both "sign up free" and "contact sales" nav links, regardless of what's actually gated — a naive keyword scraper can't tell them apart.

02
where gating actually clusters

By business model, not category. Payments and B2B ad platforms (LinkedIn, Brex, Ramp) are gated by partner/customer status. Dev-infra and productivity tools are almost universally instant self-serve.

03
confidence tags were well-calibrated

Every "low confidence" row we later checked with a real search needed correction. Every "high confidence" row checked held up. The self-rating worked.
